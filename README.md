# Yesmin AI — Termux Android project

This is a native Kotlin/Jetpack Compose Android MVP, not a website. Package: `com.yesmin.ai`.

## Included and implemented
- Native Android Compose interface with Home, Chat, Calling, Coding, Tools, Memory, and Settings sections.
- Gemini text generation over HTTPS using the configurable Gemini API model ID.
- API key save/remove and connection test. The key is saved in app-private SharedPreferences, **not encrypted**; do not treat this as production-grade secret storage.
- One-turn Android SpeechRecognizer input and TextTo-Speech spoken replies.
- Basic supported intents for YouTube search, camera, Android Settings, browser, and maps.
- Manual local notes with delete and clear-all.
- Coding mode prompt and copyable/selectable response text.

## Not included yet
- Gemini Live API real-time bidirectional audio streaming.
- Room database; current manual notes use app-private SharedPreferences.
- AccessibilityService, notification reading, screen capture, calendar/reminders, wake word, web search, OCR and document parsing.
- Production secret protection or backend proxy.
- Automated tests or verified APK build.

Buttons are limited to implemented actions. Speech recognition availability depends on the phone's installed speech service and network.

## Requirements
- Android device running Android 8.0/API 26 or later for the app.
- Termux from a trusted source, Java 17, Gradle 8.9, Android SDK platform 35 and build-tools.
- Internet access to download dependencies.

## Termux setup (Android SDK)
Termux package repositories and Android SDK packaging vary by device. First try:
```sh
pkg update && pkg upgrade
pkg install openjdk-17 gradle unzip git
java -version
gradle --version
```

Install/configure Android command-line tools and platform 35 using an SDK distribution supported by your Termux environment. Set `ANDROID_HOME` to your actual SDK path, for example (change this to the path you really installed):
```sh
export ANDROID_HOME="$HOME/android-sdk"
export ANDROID_SDK_ROOT="$ANDROID_HOME"
export PATH="$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin"
```
Confirm these exist before building:
- `$ANDROID_HOME/platforms/android-35/android.jar`
- `$ANDROID_HOME/build-tools/35.0.0/`

If your environment cannot run Android build tools natively, build on a supported Linux/Android build environment instead. A phone-only build is not guaranteed by Termux package availability alone.

## Build
From the extracted project root:
```sh
gradle wrapper --gradle-version 8.9
chmod +x gradlew
./gradlew --version
./gradlew assembleDebug
```
The wrapper JAR is intentionally generated by the installed Gradle command in Termux rather than bundled as a potentially invalid binary. The generated wrapper files should appear in `gradle/wrapper/`.

Expected APK:
`app/build/outputs/apk/debug/app-debug.apk`

Install (if Android permits local APK installation):
```sh
termux-setup-storage
cp app/build/outputs/apk/debug/app-debug.apk ~/storage/downloads/YesminAI-debug.apk
```
Open the APK from Downloads and allow installation for the app used to open it. Or, if Android platform-tools/ADB is configured:
```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Configure Gemini
1. Create an API key in Google AI Studio for the Gemini API.
2. Launch Yesmin AI, open Settings and paste the key.
3. Save the key, leave model as `gemini-2.5-flash` or set a currently available model for your account, then press Test Gemini connection.
4. If you see 400/403/404/429 errors, check model availability, API access, billing/quota, key restrictions and network.
5. Never share your API key in chat, screenshots, source control, or public ZIPs.

The model name is configurable because model availability changes. This project calls the documented `generateContent` REST endpoint. It does not claim to implement Gemini Live.

## Troubleshooting
- `SDK location not found`: set `ANDROID_HOME`/`ANDROID_SDK_ROOT` to a valid SDK.
- `platform android-35 not found`: install SDK Platform 35.
- Java version error: use JDK 17.
- Gradle download failure: check internet and run `gradle wrapper --gradle-version 8.9` again.
- Gemini 404: model ID unavailable for your API/account; use a supported model from the official model list.
- Gemini 401/403: API key, permissions or API enablement issue.
- Gemini 429: quota/rate limit.
- Voice fails: allow microphone permission and ensure Android speech recognition is installed/enabled.
- `INSTALL_FAILED`: enable permission to install unknown apps for the file manager/browser you used.

## Security
The API key is stored in app-private preferences and masked in the UI, but app-private storage is not equivalent to encryption against a compromised/rooted device. For a public production app, use a backend service that protects credentials, applies rate limits and does not expose a shared provider key to clients. Do not embed a private key in source code.
